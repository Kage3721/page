Question 1:
What does CSS stand for?

Cascading Style Sheets    Your answer  
Computer Style Sheets
Creative Style Sheets
Colorful Style Sheets

正確答案（英文原文）：Cascading Style Sheets

【中文翻譯】
題目：CSS 是什麼英文名稱的縮寫？
選項 1：階層式樣式表（也常譯為串接樣式表）

選項 3：創意樣式表

<link rel="stylesheet" type="text/css" href="mystyle.css">    Your answer  
<stylesheet>mystyle.css</stylesheet>

正確答案（英文原文）：<link rel="stylesheet" type="text/css" href="mystyle.css">

【中文翻譯】
題目：引用外部樣式表的正確 HTML 寫法是什麼？
選項 1：使用 link，rel 指定 stylesheet，href 指定 CSS 檔案

外部 CSS 使用 link 元素，href 指向檔案，rel="stylesheet" 表示樣式表。原題的 type="text/css" 是有效寫法，這裡完整保留；HTML5 中通常也可省略 type。style 元素則用來寫內部 CSS。

Question 6:
Which is the correct CSS syntax?

body {color: black;}    Your answer  
{body:color=black;}
body:color=black;
{body;color:black;}

正確答案（英文原文）：body {color: black;}

【中文翻譯】
題目：哪個 CSS 語法是正確的？
選項 1：body 選擇器後接大括號，內含 color: black;（正確）
選項 2：把 body 放在大括號內，使用等號（不正確）
選項 3：未使用宣告區塊，且使用等號（不正確）
選項 4：選擇器放在大括號內，屬性與值使用分號分隔（不正確）
中文答案：選項 1，body 選擇器後接大括號，內含 color: black;（正確）

【解析】
CSS 規則是「選擇器 { 屬性: 值; }」。選擇器在大括號外，屬性與值之間用冒號，宣告間用分號。color 是文字顏色，black 是黑色；不要使用等號。

多個選擇器共用規則時使用逗號，例如 h1, p {color:red;}，表示 h1 與 p 都套用。空格建立後代關係，加號建立相鄰同層關係，並不是單純的群組分隔符號。comma 是逗號。

【英文原文】
Question 25:
What is the default value of the position property?

static    Your answer  
absolute
fixed
relative

正確答案（英文原文）：static

【中文翻譯】
題目：position 屬性的預設值是什麼？
選項 1：static：一般文件流中的預設定位
選項 2：absolute：絕對定位
選項 3：fixed：固定定位
選項 4：relative：相對定位
中文答案：選項 1，static：一般文件流中的預設定位

【解析】
position 的初始值是 static，元素依一般文件流排列，top、right、bottom、left 不會像定位元素那樣移動它。relative、absolute、fixed 都需要另外設定，並不是預設值。
