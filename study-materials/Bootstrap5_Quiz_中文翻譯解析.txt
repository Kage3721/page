【英文原文】
Question 1:
The .container class provides a full width container, spanning the entire width of the screen

False    Your answer  
True

正確答案（英文原文）：False

【中文翻譯】
題目：.container 類別提供全寬容器，橫跨整個螢幕的寬度。
選項 1：錯誤
選項 2：正確
中文答案：選項 1，錯誤

【解析】
這個敘述錯誤。全寬容器使用 .container-fluid；.container 在各個響應式斷點會有相應的最大寬度。在小螢幕上 .container 也可能接近全寬，但不能因此認為它在所有尺寸都橫跨整個螢幕。full width 是全寬，spanning 是橫跨。

Question 25:
Which class can be used to float an element to the right of the page?

.float-end    Your answer  
.float-r
.float-start
.float-right

正確答案（英文原文）：.float-end

【中文翻譯】
題目：哪個類別可讓元素浮動到頁面的右側？
選項 1：.float-end：向結束側浮動
選項 2：.float-r：不是 Bootstrap 標準類別
選項 3：.float-start：向起始側浮動
選項 4：.float-right：舊版命名，不是 Bootstrap 5 的答案
中文答案：選項 1，.float-end：向結束側浮動

【解析】
在一般由左至右的 Bootstrap 版面中，結束側 end 是右側，所以選 float-end。Bootstrap 5 改用 start 與 end 命名；在相應的 RTL 版面中，方向會反轉。float 的實際位置也受所在容器影響，不必然是整個頁面最右端，且 float 不會用來排列 flex 項目。
補充核對來源：https://getbootstrap.com/docs/5.3/migration/
